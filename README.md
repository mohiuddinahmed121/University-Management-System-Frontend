# University Management System

A full-stack University Management System designed to manage students, instructors, courses, sections, registrations, and academic results.

## Features

- Role-based authentication for Admin, Instructor, and Student
- User registration and login
- Department, course, and section management
- Student course registration
- Instructor result submission and update
- Student result viewing
- bKash payment integration

## Technology Stack

**Frontend:** Next.js, TypeScript, Tailwind CSS

**Backend:** Node.js, Express.js, TypeScript

**Database:** PostgreSQL, Prisma ORM

**Authentication & Validation:** JWT, Zod

**Payment:** bKash

## Deployment

- Frontend: Vercel
- Backend: Deployed API server
- Database: PostgreSQL

## Getting Started

Clone the repository, install dependencies, configure the required environment variables, and run the frontend or backend according to its project setup.

```bash
npm install
npm run dev
```

## Project Purpose

This project aims to simplify university academic management through a centralized system with role-based access and online payment support.
